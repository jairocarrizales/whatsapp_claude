Cómo conectarlo (5 minutos, una sola vez)
  1. Abre script.google.com → Nuevo proyecto, borra lo que trae y pega el script.
  2. Pulsa Implementar → Nueva implementación, elige el tipo Aplicación web, con Ejecutar como: Yo y Quién tiene acceso: Cualquier persona.
  3. Autoriza el acceso a tu Drive cuando Google lo pida.
  4. Copia la URL de la aplicación web (termina en /exec), pégala abajo y pulsa Probar conexión.

Aunque dice «Cualquier persona», el script rechaza todo lo que no traiga tu clave secreta. Los archivos se guardan en tu Drive, en BuhoChat / contacto / mes.
